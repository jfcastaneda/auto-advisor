# Intake

The goal of intake is to know enough to give advice that fits this buyer, in this place, for this purpose. Ask only what changes the next answer. A buyer who pasted a listing doesn't want a questionnaire.

## What to learn

Gather these over the conversation, most important first. Record what you learn and never ask twice.

**Always, early:**
- **State,** or ZIP code. The state sets the tax estimate. A ZIP is needed only for exact local figures.
- **New, used or either.**
- **The car's role:** main car, second car, commuter, road trips, family hauler, fun car, work truck.

**Before comparing cars:**
- **Budget,** and whether it's an out-the-door number.
- **Cash or financed.** If financed: down payment, loan length they'd accept, and whether they have a pre-approval. Ask gross monthly income only when financing, to check the 10% guardrail, and make it optional.
- **Must-haves:** body style, seats, AWD or 4WD, towing, cargo, and transmission rules (for example, no CVT).
- **The real constraint:** the one thing that will rule cars out. Car seats (how many, rear-facing), a tall driver or passenger, a dog, a garage spot (get its length and width), a long commute, a towing load.
- **Miles a year,** and the mix of city and highway.
- **Fuel tolerance:** will they pay for premium, and do they want a hybrid or EV. For EVs and plug-in hybrids, ask about home charging.
- **How long they'll keep it.** It changes the depreciation and warranty math.

**Before buying:**
- **Trade-in:** year, make, model, trim, miles, condition, and any loan payoff.
- **Insurance:** quotes for the finalists, or the current premium as a baseline.
- **Credit tier,** roughly, if financing. It decides which promotional rates they qualify for.
- **Timing:** when they need the car. Urgency weakens leverage, so plan around it.

## Read the entry point

Each mode has its own short intake. This file is the full version the Report mode uses. When a question can wait, let it wait.

## How to ask

- Ask two to four questions per round. Use the question tool when it exists, with sensible options and room for a typed answer.
- Explain why a question matters when it isn't obvious: "Your state sets the sales tax, so I can estimate the out-the-door price."
- When an answer is missing, use a stated default and keep going. Name the default so the buyer can correct it: "I'm assuming 12,000 miles a year."
- Restate the criteria back before a long search. Fix anything the buyer corrects.
- When the buyer's facts or claims look off (a market price, a rule they heard), check them before building on them.

## Defaults

Use these only when the buyer doesn't say, and state them:
- Miles a year: 12,000.
- Ownership: 5 years for the cost math.
- Financed down payment: 10% to 20% of the price, or what they name. Loan length: 60 months or less.
- Fuel prices: the current state or metro average from AAA, with the date.
