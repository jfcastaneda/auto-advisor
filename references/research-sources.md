# Where to Research

Start with the primary source for each kind of fact. Cross-check only the facts that would change the verdict. Cite each source with the date. When a page can't be reached, say so and use the next source on the list.

| Question | Primary sources | Second sources |
|---|---|---|
| Fuel economy, fuel grade, EV range | fueleconomy.gov (EPA), the owner's manual or the maker's spec page by model year | Window sticker by VIN |
| Recalls, investigations, service bulletins | nhtsa.gov/recalls by VIN, NHTSA complaints and TSBs | The maker's owner site |
| Crash ratings | NHTSA star ratings, IIHS ratings for the exact model year | |
| Teen-driver safety | IIHS and Consumer Reports' yearly "Safe vehicles for teens" list (iihs.org/ratings/safe-vehicles-for-teens) | NHTSA star ratings for the exact model year |
| Reliability and failure modes | Consumer Reports reliability, NHTSA complaints by component | Owner forums and model-specific subreddits, independent shop write-ups |
| Factory maintenance schedule | The maker's owner site or owner's manual for the year and engine | Dealer service menus (check them against the maker) |
| Incentives, rebates, promotional APR, lease deals | The maker's official offers page for the buyer's ZIP | Edmunds incentives, regional dealer ads |
| Market price, discounts off MSRP | Edmunds and KBB price data, live listings in the buyer's radius | CarGurus price ratings, TrueCar |
| Days on market, price drops | The listing site's history (CarGurus, Cars.com, Autotrader) | VIN search across sites |
| Depreciation and resale | CarEdge depreciation curves, Edmunds and KBB values | Auction-based values where available |
| Repair cost averages | RepairPal, the model's known-failure parts prices | Independent shop quotes |
| Insurance | The buyer's own quotes | State insurance department averages for a rough range |
| Taxes, fees, dealer rules, used-car law | The state revenue department, DMV, attorney general (see `locale.md`) | |
| Fuel prices | AAA state and metro averages | |
| Window sticker and options | The maker's window sticker lookup by VIN, where offered | VIN decoders |
| Vehicle history | Carfax, AutoCheck, NMVTIS for title brands | The seller's service records |
| Loan rates | The maker's finance offers, local credit unions, bank rate pages | Current national averages for the buyer's credit tier |

Claude can't reliably get these. Ask for them, say why, and work with what you have until they arrive.

**Claude can't pull a Carfax or AutoCheck report directly.**

| Need | Ask the buyer to | Why |
|---|---|---|
| Carfax or AutoCheck report | Ask the dealer for the free report link, or buy one, and paste the text or a screenshot | Accidents, title brands, owners and service history for this exact car |
| Window sticker | Ask the dealer for it, or use the maker's VIN lookup if they have one | The car's real options |
| Itemized out-the-door quote | Get it in writing from the dealer | The only price that counts |
| Service records | Share receipts or the dealer's service printout | Line the history up against the schedule |
| Pre-purchase inspection report | Share the shop's written report | Real measurements for this car |
| Insurance quotes | Get quotes for the finalists from their insurer | Insurance can swing more than fuel between cars |
| Loan pre-approval | Get one from a credit union or bank | The rate the dealer has to beat |
| Trade-in cash offers | Get written offers from online buyers | The trade-in baseline |
| A listing that won't load | Paste the text or a screenshot | Sites often block automated reads |
| Photos of a problem | Take them in daylight, from the angles named | Photos settle what descriptions can't |

## Rules

- **Model year matters.** Specs, fuel grade, ratings and failure modes change by year, engine and transmission. Match all three.
- **Dealer feature lists are unreliable.** The window sticker by VIN settles options.
- **Forums are evidence of patterns, not prices.** Count recurring reports. One angry post isn't a failure mode.
- **Recency matters.** Prices, incentives and rates change monthly. Check dates and prefer this month's data.
- **Name what you couldn't verify.** Never fill a gap with a remembered number presented as current.
- **One try, then ask.** If a source is paywalled, blocked or won't load, don't hunt for workarounds or mirrors. Ask the buyer for it.
- **When listing sites block reads,** fall back to Edmunds and KBB price ranges for the comparables, and label them unverified. Ask the buyer only for the listing they're considering.
